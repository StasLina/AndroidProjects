Работы по дисциплине "Разработка мобильных приложений"

Самостоятельная работа.
1. Создайте новый проект в Android Studio. Добавьте
зависимости для Retrofit и RecyclerView в build.gradle;
2. Создайте класс Character для представления данных
персонажах. Определите необходимые поля и методы для
сериализации и десериализации данных из JSON;
3. Создайте интерфейс Rick And Morty Api для взаимодействия с
API. Реализуйте методы для получения данных о персонажах;
4. Создайте три класса ViewHolder: HumanViewHolder,
AlienViewHolder, OtherViewHolder. Реализуйте методы bind для
каждого ViewHolder, чтобы отображать соответствующие
данные;
5. Создайте адаптер для RecyclerView. Реализуйте методы
onCreateViewHolder, onBindViewHolder и getitemviewtype для
использования различных ViewHolder в зависимости от типа
персонажа;
6. Настройте RecyclerView в активности или фрагменте.
Обеспечьте загрузку данных из API и обновление RecyclerView.

Добавьте зависимости для kotlinx.coroutines в build.gradle. Настройте ViewModel для использования корутин;
Добавьте companion object в класс, отвечающий за взаимодействие с API, для хранения базового URL и других констант. Реализуйте метод для создания экземпляра Retrofit внутри companion object;
Реализуйте функции для выполнения сетевых запросов с использованием корутин. Обновите UI на основе полученных данных в основном потоке;
Добавьте обработку возможных ошибок сетевых запросов в корутинах. Реализуйте отображение сообщений об ошибках в UI;
Используйте корутины для выполнения длительных операций в фоновом потоке, таких как:
Получение данных о персонажах из API;
Парсинг полученного JSON-ответа в объекты Kotlin;
Обеспечьте правильное управление жизненным циклом корутин с помощью viewModelScope или lifecycleScope;
Напишите тесты для проверки работы корутин и взаимодействия с API, включая:
Тесты на успешное получение данных из API;
Тесты на обработку ошибок при сетевых запросах (например, симуляция сетевых сбоев);
Тесты на корректное обновление UI при получении данных;
Тесты на правильное управление жизненным циклом корутин и их отмену при уничтожении компонентов;
